Databricks & Unity Catalog

LakePulse: FinTech REST API to Atomic SCD Type 2 Engine

View Code & DAB Config

A metadata-driven Lakehouse pipeline deployed via Databricks Asset Bundles (DABs). Extracts paginated FinTech KYC updates with exponential backoff into Unity Catalog Managed Volumes, ingests incrementally via Auto Loader (cloudFiles), and executes a single-pass atomic PySpark SCD Type 2 MERGE INTO using null-safe SHA-256 change detection and Delta Liquid Clustering. 

flowchart LR
    API["FinTech REST API\n(Retry 429/5xx)"] ==>|"NDJSON"| VOL[("UC Volume\nraw_api_json")]
    VOL ==>|"Auto Loader\n(AvailableNow)"| BRZ[("Bronze Delta\ncustomer_events_raw")]
    BRZ ==>|"SHA-256 Diff +\nStaged Merge Key"| SLV[("Silver SCD Type 2\ndim_customer_scd2")]
    BRZ -.->|"Row Count Check"| ABC[("ABC Audit Log\npipeline_audit_log")]
    SLV -.->|"Delta Metrics"| ABC

Single-Pass SCD2 Merge

Uses a staged merge_key union pattern to expire old records and insert new active versions in a single atomic Delta commit.
